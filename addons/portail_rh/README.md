# Portail RH

Module Odoo 17 Community pour les demandes de deplacement, de fournitures et d'attestation, le portail employe, le reporting RH et l'integration des pointages ZKTeco.

Version : `17.0.2.1.0`.

Le jeu de donnees local configure Bravico SARL AU, son identite visuelle, ses collaborateurs, ses documents internes, son assistant Bravi et les pointages ZKTeco. Il est active uniquement lorsque `PORTAIL_RH_DEMO_PASSWORD` est defini dans l'environnement.

La documentation d'installation, d'exploitation et de test se trouve dans le `README.md` a la racine du depot.
